# **App Name**: Propel Lite

## Core Features:

- Smart Messaging: AI Tool that provides suggested message content for tenant reminders and notifications based on property and tenant data. This can be configured with a prompt, and is specific to the individual property.
- Price Suggestion: AI Tool that suggests a reasonable price based on entered data about a property, and some basic market data. This tool should make a conservative recommendation and offer ways to override its assumptions, in case the property has unusual characteristics.
- Property Management: Allow property details to be entered and displayed: address, square footage, number of beds/baths, image, short descriptive text.
- Landlord Dashboard: A landlord dashboard provides a simple view to monitor and manage properties and tenants, including lease details, payment tracking, and communication logs.
- Tenant Portal: Tenant portal for viewing lease details, submitting maintenance requests, and direct communication.

## Style Guidelines:

- Primary color: Strong teal (#008080) to evoke trust and efficiency.
- Background color: Light teal (#E0F8F8), subtly desaturated to ensure readability.
- Accent color: Warm orange (#FF7F50), analogous to teal, for highlighting calls to action.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look.
- Use simple, geometric icons in a muted teal color to represent key features and actions.
- Implement a clean and intuitive layout with clear information hierarchy, prioritizing key data and actions.
- Subtle transitions and animations to enhance user experience, such as smooth loading indicators and feedback on interactions.
